# Caballero Core

Sitio web oficial de **Caballero Core by Luis Caballero**.

Caballero Core es una marca de soluciones tecnológicas enfocada en desarrollo web, sistemas, apps móviles, automatización, soporte técnico, mantenimiento y consultoría TI para negocios reales.

## Servicios

- Páginas web y landing pages
- Sistemas web y herramientas internas
- Apps móviles
- Automatización, Excel, reportes y bases de datos
- Soporte técnico y mantenimiento de equipos
- Consultoría TI para negocios

## Experiencia destacada

- Sitios web para negocios locales
- Automatización de reportes con Python, SQL y Excel
- Sistemas internos para operación restaurantera
- Apps móviles con Flutter
- Soporte e infraestructura TI
- Experiencia con ERP, Softrestaurant, TOTVS y Kepler
- Proyectos creativos bajo Caballero Game Studio
