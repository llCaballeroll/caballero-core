# Caballero Core

Sitio web oficial de **Caballero Core**, la marca tecnológica de Luis Caballero.

Tecnología que sí funciona, para negocios reales: páginas web, apps móviles, sistemas a la medida, automatización de reportes, soporte técnico y consultoría TI, todo de la mano de un solo equipo.

## Lo que hacemos

- Páginas web y landing pages que sí venden
- Sistemas a la medida para tu operación
- Apps móviles para Android e iOS
- Automatización de tareas y reportes
- Soporte técnico y mantenimiento de equipos
- Consultoría TI clara y honesta
